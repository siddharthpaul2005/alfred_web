01 · How it works

One brain. Many hands.

A single orchestrator knows every agent, every device and every task. Small, focused agents do the work. Nothing clicks on your screen except one carefully guarded component called Hands.

Orchestrator routes · gates · records
Agent

Hover an agent

Each agent is its own program that does one domain well, and each action it offers carries a risk tier.

1

You ask, anywhere

Voice, hotkey, phone, Telegram, a browser tab. Same ALFRED, same task list.

2

It plans

A fast local router handles simple commands offline. A cloud planner breaks big goals into steps.

3

It checks permission

Every step has a risk tier. Reversible steps run. Irreversible ones wait for your yes.

4

It acts and verifies

The right agent on the right device does the step, then looks again to confirm it actually worked.

5

It records

Every step, approval and result lands in a tamper-evident log you can check from any device.

      04 · Trust

      No limits on reach. Real brakes.

      Giving an AI your whole computer only works if you can trust it with your whole computer. ALFRED's safety isn't a policy page. It's built into how every single step runs.

      0

      Free

      Runs immediately.

      • Read email
      • Search files
      • Search the web
      1

      Logged

      Runs, is recorded, and can be undone.

      • Move a file
      • Label an email
      • Create your own event
      2

      Confirm

      Waits for your yes, on whatever device you're holding.

      • Send, post, pay
      • Delete, install
      • Anything leaving the machine

      Forgot to set a tier? It's treated as tier 2. When in doubt, ALFRED asks.

      Autonomy dial

      You decide how much it does alone

      Trusted only skips a confirmation you've given the same way five times, with the exact same details. Payments and deletes never become automatic.

      Tamper-evident audit

      Try to rewrite history

      Each log entry's fingerprint includes the one before it. Change any old entry and every entry after it breaks. Go on, tamper with one.

      ✓ Audit verified · 6 entries intact

      Kill switch

      One hotkey, or just the word “stop”, cancels every running task on every device.

      Untrusted text is data

      Emails, web pages and messages are labeled as data, so a sneaky email can't give ALFRED orders.

      Paired devices only

      Each device pairs once with a key you approve. Lose your phone, revoke it from anywhere.

      Secrets in the vault

      Passwords stay in Windows Credential Manager or Android Keystore. Never in files, never in a model's prompt.

      Signed agents only

      Only agents you built or approved can connect. No open skill store full of strangers' code.

      Never re-run blindly

      If a risky step was interrupted, ALFRED asks again instead of guessing whether it happened.

      Versus Grok

      Grok is a superb mind with live web and X data and a fast voice. It lives in a chat window. ALFRED takes the same kind of intelligence and gives it hands on your desktop, your phone and your files.

      Versus Meta's Muse

      Muse lives inside Meta's apps and Meta's cloud. ALFRED lives on your machines, keeps its memory locally, and answers to you, not to an ad platform.

      Versus OpenClaw

      OpenClaw proved people want an agent that acts on its own. It also showed the cost of skipping safety: unvetted skills and plaintext secrets. ALFRED keeps the autonomy and adds the brakes.
